# 05 — FALLING INTO THE MARIANA TRENCH — script & shot list

Format: 1920×1080, 24 fps, **352.0 s (5:52)**. One continuous descent from the surface of the western Pacific to the floor of Challenger Deep (≈ 10,935 m), with a live HUD (depth, pressure, water temperature, sunlight) and a linear 0–11 km depth gauge. Voice: Kokoro am_michael, speed 0.94. 703 words. Timeline locked to the measured voice (`audio/timeline.py` → `audio/placement.json`); the camera depth is keyed so that each depth is reached when the narrator names it.

Visual spine: daylight → turquoise → blue → indigo → black (red goes first). Our own lamp fades in from ~450 m; from 1,000 m the only light is alive. Scale markers (dashed lines + labels) cross the frame as we pass them; Burj Khalifa, Everest and the Titanic bow appear as thin ghost line drawings.
