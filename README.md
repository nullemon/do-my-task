# do-my-task

Two independent projects:

| Folder | What |
|---|---|
| [`newsalert/`](newsalert/README.md) | Breaking-news alert system for celebrities, anime, manga and TV. Rings your laptop within 1–2 minutes through ntfy.sh. Alert only: it never posts anything. |
| [`tabnap/`](tabnap/README.md) | Chrome/Edge extension that frees RAM by unloading tabs you aren't viewing, with a list of sites that are never unloaded. |
