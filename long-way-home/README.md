# The Long Way Home — Episode 1

A 60-second vertical (1080×1920, 24 fps) animated short for Facebook Reels, made entirely in code:
every frame is drawn on an HTML canvas, and the score and sound effects are synthesized in Python.
Nothing is generated by an image or video model, so there is no licensing question about the pictures or the music.

## Files

| Path | What it is |
|---|---|
| `index.html` | Loads the fonts and the film scripts; open it in Chrome and call `renderFrame(f)` to see any frame |
| `src/lib.js` | Math, color, bloom/emissive layer, rain, fog, grain, vignette, lens flare, captions |
| `src/chars.js` | Rigged silhouettes: Rusty (side view with walk/trot/gallop/sit, back view sit/stand/walk), the puppy, Dad, Lily, the car, the school bus |
| `src/env.js` | Skies, clouds, mountains, trees, grass, roads, the gas station |
| `src/scenes.js` | The eleven shots, each a function of time |
| `src/main.js` | Scene timeline and transitions, grading, captions, the title card |
| `render.cjs` | Headless Chromium renderer → ffmpeg (`--stills 1.5,10` or `--video out/video_silent.mp4`) |
| `audio/soundtrack.py` | Original piano/strings/music-box score and all sound effects (numpy only) |
| `finalize.sh` | Muxes video + audio into `deliver/` |
| `fonts/` | Lora, Cinzel, Cormorant Garamond (SIL Open Font License, from github.com/google/fonts) |

## Rebuild

```bash
node render.cjs --video out/video_silent.mp4
python3 -I audio/soundtrack.py
./finalize.sh
```

## Changing things

- Caption text and timing: `CAPTIONS` in `src/main.js`.
- Shot timing and transitions: `SCENES` in `src/main.js`.
- The dog's look: `DOG_BODY`, `HEAD_TOP`, `EAR` (side view) and `DB_SIT` / `DB_STAND` (back view) in `src/chars.js`.
- Music: `compose()` in `audio/soundtrack.py` (melodies `M1`–`M3`, chords in `CH`).
